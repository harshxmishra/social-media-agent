# Python Social Media Agent

This directory contains the Python conversion of the LangGraph-based Social Media Agent.

## Setup

1.  Ensure you have Python 3.10+ and Poetry installed.
2.  Navigate to this directory (`python_langgraph_agent`).
3.  Run `poetry install` to install dependencies.
4.  Set up your environment variables by copying `.env.example` (to be created) to `.env` and filling in the required API keys.
